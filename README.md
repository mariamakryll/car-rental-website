# Car Rental Website

A modern car rental website with online booking capabilities.

## Features

- Browse 9 different cars across various categories (Sedan, SUV, Luxury, Sports, Electric)
- Filter cars by category, price range, and search functionality
- View detailed car information including features and descriptions
- Simple online booking form with date selection
- Responsive design with Bootstrap styling

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Logo

Replace `frontend/public/logo.png` with your actual logo file to customize the branding.
